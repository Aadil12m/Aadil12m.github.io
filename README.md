# Muhammad Aadil, portfolio

Static site for GitHub Pages. No build step: edit the files and push.

| File | What it is |
| --- | --- |
| `index.html` | The portfolio. Layout and styles at the top, the five canvas simulations in the first script, nav and media code in the last script. |
| `lab.html` | The 3D lab (Three.js). Linked from the nav and the hero. |
| `content.js` | Your résumé file name and the photos and videos for each project. Edit this, not `index.html`. |
| `media/` | Put robot photos and videos here, then list them in `content.js`. |
| `favicon.svg`, `og.png` | Browser tab icon and the preview image shown when the link is shared. |

## Add real photos, video or a résumé

Open `content.js`. The comments at the top show the format.

## Preview on your computer

Double-click `index.html`, or run `python -m http.server` in this folder and open http://localhost:8000.
